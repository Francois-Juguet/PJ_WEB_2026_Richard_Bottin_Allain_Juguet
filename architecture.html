Flux principal — Requête authentifiée
1
Action utilisateur
L'utilisateur clique sur un bouton (ex : "Ajouter à l'itinéraire"). React déclenche un appel Axios.
2
Requête HTTP
Axios envoie POST /api/itineraries avec le JWT dans le header Authorization: Bearer …
3
Validation JWT
requireAuth() vérifie la signature HMAC-SHA256 et l'expiration. Si invalide → 401.
4
Requête SQL
Le contrôleur PHP exécute une requête préparée via PDO. MySQL retourne le résultat. PHP formate en JSON.
5
Mise à jour UI
React reçoit la réponse JSON → met à jour le state (Context ou useState) → re-render automatique des composants.
