Comment une page s'affiche — flux de données

Exemple avec la page Destinations

1
L'utilisateur navigue vers /destinations
React Router lit l'URL et affiche le composant Destinations.jsx
2
useEffect() se déclenche au chargement
React appelle automatiquement fetchDestinations() une fois le composant monté
3
api.js envoie la requête HTTP
Axios fait un GET vers le backend PHP
GET /destinations/index.php?category=beach&sort=rating
4
Le backend PHP répond en JSON
PHP interroge MySQL, filtre les résultats, retourne un tableau d'objets
{"data": [ {"id":1, "name":"Bali", "price_from":899} … ]}
5
React met à jour l'état
setDestinations(data) déclenche un re-rendu automatique de la page
6
La liste s'affiche à l'écran
React dessine une carte par destination dans le tableau — sans recharger la page

L'authentification — comment fonctionne le JWT

JWT = JSON Web Token — une chaîne signée qui prouve l'identité de l'utilisateur

Connexion (une seule fois)

1
Saisie email + mot de passe
L'utilisateur remplit le formulaire Login.jsx
2
Envoi au backend
POST /auth/login.php
3
PHP vérifie le mot de passe
Comparaison avec le hash stocké en base (bcrypt)
4
PHP retourne un token
{"token": "eyJhbGci…"}
5
React stocke le token
Sauvegardé dans localStorage pour persister après rechargement

Requêtes suivantes (automatique)

1
L'intercepteur Axios lit le token
Défini dans api.js, s'exécute avant chaque requête
2
Token ajouté dans l'en-tête HTTP
Authorization: Bearer eyJhbGci…
3
PHP vérifie et décode le token
Identifie l'utilisateur sans interroger la base de données
4
Réponse selon le rôle
Un admin voit plus de données qu'un voyageur simple
!
Si le token est invalide → 401
L'intercepteur supprime les données locales et redirige vers /login

Les contextes React — partager des données sans les passer manuellement

Sans contexte, il faudrait passer les props de composant en composant — fastidieux

AuthContext

Mémorise l'utilisateur connecté. Disponible dans toute l'application.

userobjet avec nom, email, rôle
login()connecte et stocke le token
logout()efface le token, redirige
isAdmintrue si rôle = admin

CartContext

L'itinéraire en cours de construction (équivalent d'un panier e-commerce).

currentItineraryle voyage en cours
addTransport()ajoute un vol/train
addActivity()ajoute une activité
itemCountbadge sur l'icône panier

ToastContext

Affiche des messages temporaires (4 secondes) sans recharger la page.

toast('msg', 'success')
toast('msg', 'error')
toast('msg', 'info')

Comment utiliser un contexte ?

// Dans n'importe quel composant :
import { useAuth } from '../context/AuthContext'

function MonComposant() {
  const { user, logout } = useAuth()
  return <p>Bonjour {{user.first_name}}</p>
}
